Mode-sense format note
----------------------
sg_modes -a -H emits a 10-byte MODE SENSE response (8-byte header). The
firmware's AS/400 mode-sense path replies to 6-byte MODE SENSE commands
(cmd 0x1A) which carry a 4-byte header. The capture was therefore
re-headered to the 6-byte format before being committed:

    10-byte capture: 208 B, mode_data_length=206
    6-byte stored:   204 B, mode_data_length=203 (= 0xCB)

Block descriptor confirms 522-byte sectors (consistent with AS/400 BS522).

.bin file to refresh the corresponding .inc.
